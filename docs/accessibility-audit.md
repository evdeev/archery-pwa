# Accessibility Audit

## Goals

- VoiceOver support
- Keyboard navigation
- Large touch targets
- Color contrast
- Reduced motion support

## Checklist

- Use semantic buttons.
- Add aria-label for score buttons.
- Ensure touch targets are at least 44x44.
- Avoid color-only meaning.
- Test with VoiceOver on iOS.

## Areas

- Score keyboard
- Session editor
- Settings
- Modal sheets
- Statistics charts
