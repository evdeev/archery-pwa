# App Icon Pipeline

## Source

- Master icon should be SVG.
- Export from Figma or Illustrator.
- Use 1024x1024 artboard.

## Required Sizes

- 1024x1024
- 512x512
- 192x192
- 180x180
- 152x152
- 120x120

## iOS

Use PNG only for iOS home screen icons.

## Android

Maskable icons should be generated separately.

## Naming

public/icons/icon-192.png
public/icons/icon-512.png
